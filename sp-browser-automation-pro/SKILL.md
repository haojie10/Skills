# 浏览器自动化专家 (Browser Automation Pro)

## 核心价值

通过模拟真实用户浏览器操作，可以获取：
- **公域信息**：公开网页、搜索结果、新闻动态。
- **私域信息**：内部 OA/CRM 系统、需登录的企业应用、个人账户数据。

## 核心工作流 (Snapshot-Analyze-Interact)

这是确保浏览器自动化成功率的“黄金回路”：

1. **打开 (Open)**：打开目标 URL。
2. **快照 (Snapshot -i)**：获取当前页面的“可交互元素”列表（带 @ref ID）。
3. **分析 (Analyze)**：根据 Ref ID 确定要操作的元素。
4. **交互 (Interact)**：执行 `click`、`fill`、`type` 等操作。
5. **循环**：页面变化后，必须重新执行第 2 步获取最新的 Ref ID。
6. **收尾 (Close)**：任务完成后关闭标签页，释放资源。

## 高级操作指南

### 1. 元素定位与 Ref ID
- `snapshot -i`：只显示按钮、链接、输入框等可操作元素，极大减少冗余信息。
- **注意**：Ref ID 是临时的。页面刷新、导航或动态加载后，ID 会失效，必须重新执行 `snapshot`。

### 2. 信息提取策略
- **结构化提取**：利用 `eval` 直接执行 JS 提取大段正文或复杂 JSON。
- **视觉验证**：关键步骤后使用 `screenshot` 截图，验证页面状态是否符合预期。

### 3. 网络与调试
- **流量监控**：通过 `network requests` 观察接口返回的数据，这比解析 DOM 更稳定。
- **拦截与 Mock**：利用 `network route` 拦截广告或模拟特定的 API 响应。

## 避坑指南 (Red Flags)
- **绝对不要**：在没有重新 `snapshot` 的情况下尝试操作变动后的页面。
- **绝对不要**：遗留大量未关闭的浏览器标签页。
- **技巧**：如果页面嵌套太深，尝试使用 `snapshot -d [深度]` 或 CSS 选择器限定范围。
