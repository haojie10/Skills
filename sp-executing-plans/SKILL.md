# 执行计划

## 概述

加载计划、批判性审查、执行所有任务、完成时报告。

**开始时声明：** "我正在使用 `sp-executing-plans` 技能来实现这个计划。"

**注意：** 如果当前平台支持子智能体（如 Claude Code 或 Codex），应当优先使用 `sp-subagent-driven-development` 技能。此技能适用于不支持子智能体的环境。

## 流程

### 第 1 步：加载并审查计划
1. 读取计划文件。
2. 批判性审查 - 识别关于计划的任何疑问或担忧。
3. 如果有疑虑：在开始前与你的用户伙伴提出。
4. 如果没有疑虑：创建 TodoWrite 任务清单并继续。

### 第 2 步：执行任务
对于每个任务：
1. 标记为进行中 (in_progress)
2. 严格遵循每个步骤（计划应当包含小而易执行的步骤）
3. 按照指定运行验证测试
4. 标记为完成 (completed)

### 第 3 步：完成开发
在所有任务完成并验证后：
- 声明："我正在使用 `sp-finishing-a-development-branch` 技能来完成这项工作。"
- **必需子技能：** 调用 `sp-finishing-a-development-branch`
- 按照该技能指引验证测试、展示选项并执行选择。

## 何时停止并请求帮助

**在以下情况立即停止执行：**
- 遇到阻塞问题（缺少依赖项、测试失败、指令不明确）
- 计划存在阻碍开始的严重漏洞
- 你不理解某个指令
- 验证反复失败

**请求澄清，而不是靠猜测。**

## 何时重新审视前面的步骤

**在以下情况回到审查（第 1 步）：**
- 用户基于你的反馈更新了计划
- 基础方法需要重新思考

**不要强行通过阻塞项** - 停下来询问。

## 切记
- 严格遵循计划步骤。
- 不要跳过验证环节。
- 只有在明确授权下才能在 main/master 分支上实现。
