# CRM DOM 结构参考

首次执行 Skill 时需确认以下选择器，确认后更新本文件。

## 邮件列表页

| 元素 | 选择器 | 状态 |
|---|---|---|
| 邮件表格行 | `.el-table__row` | ⏳ 待确认 |
| 主题列 | `td:nth-child(2)` | ⏳ 待确认 |
| 发件人列 | `td:nth-child(3)` | ⏳ 待确认 |
| 摘要列 | `td:nth-child(4)` | ⏳ 待确认 |
| 翻页 - 下一页 | `.el-pagination .btn-next` | ⏳ 待确认 |
| 翻页 - 页码按钮 | `.el-pagination .number` | ⏳ 待确认 |
| 总条数显示 | `.el-pagination__total` | ⏳ 待确认 |

| 元素 | 选择器 | 状态 |
