# 📝 深度业务总结模板 (Deep Business Summary Template)

> [!TIP]
> 使用此模板处理全量邮件正文，确保业务细节 100% 还原。

## 👥 客户/项目：{Customer Name / Project Name}

### 1. 业务背景 (Context)
- **关联单据**: PO# / Item# / B/L# / 进仓编号 (如 NBDCG26KA19A)
- **事件说明**: 简述邮件起因（如“货代发送费用对账单”、“客户要求修改标签”）。

### 2. 核心更新 (Key Updates)
- **数据明细**: 
  - (若是费用) 列出体积、占比、金额明细。
  - (若是进度) 列出 ETD/ETA、生产完成率。
- **重要变更**: 明确指出哪些信息变了（如“船期从 5/4 延后至 5/11”）。

### 3. 待办动作 (Action Required)
- [ ] **用户操作**: 明确需要用户执行的动作（如“3日内确认账单”、“重新签发符合FSC要求的PI”）。
- [ ] **回复建议**: 建议的回复话术或需要准备的附件。

### 4. 风险预警与截止日期 (Risk & Deadline)
- ⚠️ **截止日期**: {YYYY-MM-DD}
- 🚨 **风险点**: (如“逾期无法开票”、“不回复视为默认账单无误”、“可能导致清关延迟”)。
