# Agent 开发与交互设计标准

## 概述

本技能定义了构建高性能、可预测的 AI Agent 系统的不变量和交互规范。它强调了系统在面对人类和 AI 两类用户时的透明度与确定性。

## 设计不变量 (Design Invariants)

在编写任何 Agent 工具或处理逻辑时，必须遵守以下铁律：

1. **响应确定性 (INV-1)**：所有操作响应必须包含唯一的标识符（如 `tab ID`）和单调递增的序列号（`seq`），严禁状态回退。
2. **错误自愈 (Error Structure)**：错误响应必须包含：
   - `error`: 技术原因（供 Agent 判断是否可自动修复）。
   - `hint`: 人类可读的建议（Agent 无法修复时转达给用户）。
   - `action`: 可选的修复命令（Agent 优先尝试执行）。
3. **事件隔离**：多任务/多标签页下的事件记录必须严格物理隔离，防止上下文污染。

## UX 规范（Agent 友好型）

由于 Agent 是人类与系统之间的桥梁，接口设计必须服务于 Agent 的理解：

### 1. 命名即文档
- 字段名应使用完整英文单词，例如用 `changePercent` 而不是 `chgPct`。
- 时间戳统一使用 ISO 格式。
- 返回值应携带单位（如 `"1.55%"`）或可读的大数（如 `"1.77万亿"`）。

### 2. 引导式描述
- 工具/命令的描述应遵循公式：`{动作} ({English keywords}: {核心返回字段})`。
- 这有助于 AI 在海量技能库中通过语义匹配快速锁定目标。

## 最佳实践：命令后提示
每个具有自然下一步操作的命令，在输出末尾都应包含一行提示（💡 建议）。例如：执行完安装后提示如何进行首次运行。
