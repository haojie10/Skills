# 品类与渠道洞察报告 (report-category)

本技能继承自 **Category Insight** 核心规范，为中国制造企业与外贸工厂提供全球零售渠道品类调研与对比分析工作流，生成高颜值 HTML 商业洞察报告，并自动上传发布至 GlobalTradeBuddy 平台。

---

## ⚠️ 核心铁律：严格时序门禁机制（Strict Sequential Execution Gate）

**严禁流程倒置或提前抢跑！** 整个工作流必须严格遵循以下阻塞式四步时序，**上一步未彻底完成前严禁进入下一步**：

```
[ Gate 1: 事实调研与数据穿透 ] ──► [ Gate 2: 真实痛点推导研发方案 ] ──► [ Gate 3: 定制工业概念图 ] ──► [ Gate 4: 生成报告与平台推送 ]
  (SKU/差评/代工/BOM/海运/关税)        (必须溯源 Gate 1 具体数据)            (方案确定后才出图/给词)        (强校验 54 行业白名单入库)
```

- ❌ **严禁行为**：严禁在 Gate 1 数据调研未返回前凭主观经验臆想产品研发方向；严禁在方案确定前提前输出或生成图片提示词。
- ✅ **正确行为**：先拿到第一手客观数据，基于真实差评和供应链死穴推导方案，方案确定后再定制工业级 CMF 提示词出图。

---

## 核心工作流详解

### 第一步：要素搜集与渠道穿透（Gate 1 必须完整闭环）
1. 明确分析的**品类名称**、**目标市场国家**及 **3 个对比零售渠道**（如 Home Depot, Lowe's, Dollarama, Officeworks, TJ Maxx, Target, Amazon 等）。
2. 使用 `search_web` 或并行子代理搜集目标渠道的在架 SKU、自有品牌（Private Label）与大牌结构、价格带与真实用户差评分布。
3. 追溯目标渠道在华代工厂（如沧州化妆刷、漳州计算器、澄海玩具、慈溪小家电、余姚五金等）与海关/提单数据逻辑。
4. 穿透该品类的 **HTS 海关编码**、**最惠国基础关税（MFN）** 与 **Section 301 对华加征关税**。
5. 剖析物流痛点（轻抛货运空气、纸箱厚度导致的 Amazon FBA 尺寸跳档等）。

### 第二步：基于真实痛点推导反堆料产品研发方案（Gate 2）
1. **反堆料与成本控制原则（强制执行）**：
   研发建议**严禁采用盲目堆料让成本剧增**（如乱加传感器、复杂电路、鸡肋蓝牙等）。必须优先通过**机构创新**（去螺钉/快拆/折叠）、**物流箱容率提升**（平铺折叠降海运费/压降厚度符合 FBA 标准尺寸）或**材料与结构规避税费**等方式降低 BOM 与交付成本。
2. **研发建议三要素规范（每个方案必须直接溯源 Gate 1 的真实痛点与数据）**：
   - **用户画像**：明确具体消费群体与真实使用场景。
   - **客群痛点**：深刻挖掘现有产品在使用/购买/渠道销售中的真实痛点（如开架偷件、反光、发霉、运费高）。
   - **解决方案**：基于反堆料原则，给出极具落地的工业设计方案（明确材质 CMF、结构创新点与 BOM/箱容率提升测算）。

### 第三步：定制工业级概念图与图文闭环（Gate 3 核心门禁）
1. 在 Gate 2 研发方案确认后，为 3 款概念产品定制高精度工业设计 Prompt（包含精准材质 CMF、机构结构、暖沙配色风格、`3:2` 比例、无文字水印）。
2. **生图与提词输出规则（强制）**：
   - 优先调用 `generate_image` 生成图片并 Base64 内嵌；
   - 若生图配额耗尽，**仅在对话回复中向用户输出高质量 Google Flow 提示词**供用户复制生图。
   - **❌ 严禁行为**：**严禁将英文提示词（Prompt）、代码块或 prompt-container 写入 HTML 报告中！** 最终 HTML 报告必须是面向采购商与决策者的纯净专业商业报告。
3. **未配图严禁上传平台（门禁阻塞）**：
   - **若图片尚未生成/尚未嵌入，绝对不允许将半成品报告上传发布至平台！** 此时仅输出调研方案与生图提示词，等待用户放入图片。
   - 待用户放好图片后，自动执行图片无损压缩（单图约 100-200KB）与 Base64 内嵌，更新 HTML 报告，此时方可触发 Gate 4 的平台发布。

### 第四步：生成最终 HTML 报告并执行平台推送（Gate 4 必须在图片就绪后执行）

1. **唯一强制模板骨架（Strict Template Enforcement）**：
   - 最终 HTML 报告**必须且只能以 `assets/report-template.html` 为唯一基准模板**进行组装生成！
   - **严禁自由发挥编写非标 HTML 结构或非标 CSS/Tab 样式！**
   - 必须完整保留模板原生的视觉系统与组件类名（包括 `:root` 色彩变量、Header 右上角 `.powered-by-mg` 品牌 Logo、`.meta-info-grid` 元数据栅格、`.table-responsive` 渠道对比矩阵、`.pain-point-box` 痛点卡片、`.concept-card` 概念产品展示组件、`.concept-metrics-row` 指标网格、`.takeaway-banner` 总结横幅以及 `footer` 品牌与官网链接）。

2. **模板占位符替换标准（Placeholder Mapping）**：
   - `<title><!-- REPORT_BROWSER_TITLE --></title>`：严格命名为 `标准行业-产品名称-国家-渠道调研报告`（如 `建筑及装饰材料-铝合金门窗-法国市场-Chausson Matériaux渠道调研报告`）。
   - `{{CATEGORY}}`：固定为 `product`。
   - `{{PRODUCTS}}`：必须 **100% 精准字面命中** GTB 54 个标准行业白名单。
   - `{{SUMMARY}}`、`{{REGIONS}}`、`{{CHANNELS}}`、`{{COMPETITORS}}`、`{{SUPPLIERS}}` 等元数据精准填充。
   - `<!-- REPORT_HEADER_TITLE -->` 与 `<!-- REPORT_SUBTITLE -->`：填充专业商业标题与深度摘要。
   - `<!-- CHANNEL_PRIMARY -->`、`<!-- CHANNELS_COMPARE -->`、`<!-- INDUSTRY_NAME -->`、`<!-- MANUFACTURING_REGIONS -->`：填充头部元数据网格。
   - `<!-- MAIN_CONTENT -->`：按顺序注入以下 4 大标准化业务板块（严格使用模板原生 CSS 类名）：
     - **板块一：渠道在架结构与三维横向对比矩阵**（使用 `.table-responsive` + `<table>` + `.matrix-badge` + `ul.matrix-list`）；
     - **板块二：用户差评与供应链核心痛点穿透**（使用 `.grid-2` 或 `.grid-3` + `.pain-point-box`）；
     - **板块三：基于真实痛点的 3 款反堆料研发产品卡片**（每个产品使用 `.concept-card`：左侧 `.concept-visual` 放 Base64 压缩图片，右侧 `.concept-body` 放用户画像、群体痛点、解决方案及 `.concept-metrics-row`）；
     - **板块四：贸易壁垒、准入认证与落地破局路线**（使用 `.card` + `.takeaway-banner`）。

3. **视觉与设计规范（严格遵守 `references/ui-spec.md`）**：
   - 暖沙主背景色 `#fdfbf7` + 结构辅助色 `#f6f3ec` + 焦点强调色 `#ff641e` + 主要文字色 `#2d2a26`。
   - **坚决禁用 Emoji**，所有点缀统一使用单色极细矢量 SVG 或轻沙色标签 `.matrix-badge`。
   - 纯净版面：**严禁将英文提示词（Prompt）、代码块或调试信息写入 HTML 中**。

4. **双路径存储保存**：
   生成自包含 Base64 报告后，同时保存至：
   - `d:/我的APP/Globaltradebuddy/content-pipeline/categories/[品类-市场-渠道-insight].html`
   - `d:/我的APP/品类洞察/[对应行业子目录]/[品类-市场-渠道-insight].html`

5. **自动上传平台与强断言校验**：
   - 调用 `scripts/publish_report.py`（或直接使用其 API 发布逻辑）向 `https://marketgraphic.cn/api/agent/publish` 推送报告。
   - **发布响应强断言检查（强制）**：
     - HTTP 状态码为 200；
     - `success` 字段必须为 `true`；
     - **必须校验响应中的 `ignoredCategories` 必须为空数组 `[]`**。若有被忽略分类，说明行业未命中 54 白名单，必须立即终止并自动纠偏后重推。
